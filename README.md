# Mini E-Commerce — Boats

A small e-commerce demo selling 50 boats, built with Node.js, Express, EJS, and SQLite.

## Features

- Catalog page with search and type filtering
- Boat detail pages
- Session-based shopping cart
- Checkout flow that records orders in SQLite (no real payment processing)
- Admin panel for creating, editing, and deleting boat listings

## Tech stack

- **Backend:** Node.js + Express
- **Views:** EJS templates
- **Database:** SQLite via `better-sqlite3`
- **Session/cart:** `express-session` (in-memory store)

## Getting started

```bash
npm install
npm run seed   # generates the SQLite DB and 50 placeholder boat listings/images
npm start      # http://localhost:3000
```

For auto-restart during development:

```bash
npm run dev
```

## Project structure

```
server.js            Express app entry point
db/schema.sql         SQLite table definitions
db/database.js        DB connection, applies schema on boot
scripts/seed.js        Generates 50 boats + placeholder SVG images
routes/boats.js        Catalog + boat detail routes
routes/cart.js          Cart + checkout routes
routes/admin.js         Admin CRUD routes
views/                  EJS templates
public/                 Static assets (CSS, generated boat images)
```

## Notes

- `db/miniecommerce.db` is generated by the seed script and is gitignored — run `npm run seed` after cloning.
- The `/admin` panel has no authentication; it's a demo CRUD interface, not production-ready.
- Boat images are procedurally generated SVG placeholders, not real photos.
